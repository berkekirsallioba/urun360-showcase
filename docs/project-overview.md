# Project Overview

Ürün360 is a browser-based product display and barcode/QR lookup platform designed for retail, warehouse, and service environments.

The core idea is simple: a staff member or customer scans a barcode or QR code with a standard scanner, and the product information is shown instantly on a responsive screen.

The target screens can vary by usage scenario:

- Cashier monitor
- Customer display
- Tablet
- Mobile device
- TV or kiosk screen

The application is designed for environments where product data is managed in Wolvox ERP and needs to be presented clearly at the point of interaction.

## Barcode / QR Lookup Scenario

1. A barcode or QR code is scanned.
2. The browser captures the input as keyboard-style scanner data.
3. The backend receives the lookup request.
4. Product information is retrieved through the API layer.
5. The product is shown with a clear name, price, stock information, image support, and metadata.

## Usage Areas

Ürün360 can be used in:

- Retail stores
- Warehouses
- Service departments
- Product information kiosks
- Internal stock inquiry points
- Customer-facing price and product display screens

This public repository contains only portfolio documentation and representative visuals. It does not contain source code, credentials, database details, or customer-specific implementation information.
